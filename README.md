# Musical Preference in Nonhuman Primates

A hypothetical undergraduate report written at Stony Brook in 2019, kept as a dated record. It was never run. The cell means were
invented for the assignment, and the ANOVA line still says `x.xx`.

The question was whether environment shapes musical preference in
nonhuman primates the way it is often said to shape it in humans:
three groups (bonobo, gibbon, siamang), three acoustic instruments from
their purported habitats (djembe, qin, gamelan), time spent near each
speaker as the preference measure.

The December text is the latest body. The August text is the course
paper. The Keynote is the presentation given as Project APE.
